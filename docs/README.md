# Project memory

The project memory keeps durable, reviewable context close to the hardware files.

- `decisions/` captures durable choices, their context, alternatives, and
  consequences.
- `worklog/` captures dated experiments, observations, evidence, and next steps.
- `reference/` is the searchable reference book of current project knowledge.
- `inbox/` temporarily holds material whose classification or public safety is
  unresolved.

Keep entries factual and concise. Link evidence instead of duplicating it.
