# Work log

Use one file per meaningful session or experiment, named
`YYYY-MM-DD-short-topic.md`. The work log is append-friendly evidence, not a
polished narrative.

Record what was attempted, the exact revision or setup, observations, attached
evidence, conclusions, and next steps. Separate observations from interpretations.
