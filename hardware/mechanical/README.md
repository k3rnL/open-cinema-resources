# Mechanical resources

Store editable CAD sources, drawings, dimensions, tolerances, and intentional
review or fabrication exports here. Document the authoritative source format and
the tool version that produced it.

Enclosure work is in progress. See the
[enclosure reference](../../docs/reference/topics/enclosure-appliance.md) for the
current component set and unresolved layout constraints.

[Owner-supplied enclosure views](enclosure-layout/README.md) preserve the current
layout discussion, with original filenames and checksums. Native CAD is still
missing; use the [rear-panel reference](../../docs/reference/topics/rear-panel-interface.md)
for requirements and open dimensions.

The rear-panel joint now has an accepted design baseline: see
[decision 0004](../../docs/decisions/0004-use-jlccnc-rear-panel-fastening.md) and
the [JLCCNC fabrication guidance](../../manufacturing/rear-panel-fastening.md).
It remains unreleased until applied to native CAD and checked on a first article.
